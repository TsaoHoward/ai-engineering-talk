# Synthetic Order API — canonical browser implementation (SSOT)

This directory contains the **only runnable TypeScript Order API example** for the presentation. It is synthetic/original code and fixtures, not an example generated by a named AI model. There is **no Node HTTP server**, native SQLite dependency, or second DAO/Service implementation to maintain. Node.js is needed solely for local tooling, Vite builds and Playwright tests.

## Architecture

- **AI-direct:** Controller → `OrderRepository` → parameterized SQL.
- **Project-convention:** Controller → `OrderService` → `OrderDao` → real Drizzle ORM / sqlite-proxy.
- Both use the same `DbTransport` → MSW `POST /mock/db/query` → read-only bounded SQL evaluator backed by `fixtures/orders.json` (42 deterministic orders).
- Browser MSW also intercepts `GET /mock/api/{ai-direct|project-convention}/orders` and `/status`.
- The deliberate comparison is **same functional result, different established Consumer/API envelope contract**, not an assertion that Repository/raw SQL is intrinsically incorrect.

The bounded evaluator recognizes only the SELECT/COUNT SQL shapes actually emitted by this Order API (optional status/UTC date filters, deterministic createdAt/id sort, pagination). Unknown SQL, mutation and malformed bindings are rejected; it does **not** emulate arbitrary SQL semantics or prove database compatibility.

## Development & verification

Requires Node.js 22+ for tooling. From this directory:

```sh
npm ci
npm run verify          # build + real Chromium E2E, writes generated/browser-evidence.json
npm run dev             # static Vite dev server (not an Order API backend)
npm run preview         # preview static build on the same Pages-like subpath
```

By default the Vite base is `/ai-engineering-talk/pr-preview/pr-10/order-api/`. Override with `VITE_BASE` when deploying elsewhere. Worker script, scope and API URLs must all use the same base. Use `npm run worker:init` to generate `public/mockServiceWorker.js`; this generated file is not versioned.

CI uploads the evidence report including source revision, request URL, HTTP status, JSON body, existing Consumer outcome and actual SQL plus parameters. It is evidence from **Chromium with the browser/MSW bounded interpreter**, not a real SQLite run.
